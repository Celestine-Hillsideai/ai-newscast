AI NEWSCAST — CODING AGENT MASTER SPECIFICATION

Version: 1.1
Frontend implementation: Claude Frontend Skill

PRODUCT OBJECTIVE

Build a production-quality MVP called AI NewsCast.

The application allows a user to enter a Nigerian breaking-news topic. The system searches Nigerian news outlets, extracts relevant articles, deduplicates reports, verifies facts, generates a structured news briefing, creates a 3–6 minute podcast using ElevenLabs, generates a programmatic news video using Remotion, stores media in Supabase Storage, and displays the result in a web application.

CORE PRINCIPLE

The application is an editorial pipeline:

DISCOVER
→ EXTRACT
→ DEDUPLICATE
→ VERIFY
→ SYNTHESIZE
→ WRITE
→ NARRATE
→ VISUALIZE
→ PUBLISH

Never allow the LLM to directly convert raw web results into a final video without passing through verification and structured editorial synthesis.

FRONTEND IMPLEMENTATION DIRECTIVE

The frontend must be built with the Claude Frontend Skill.

Before implementing frontend UI:
1. Read and follow the installed Claude Frontend Skill instructions available in the development environment.
2. Use the skill's recommended approach for page composition, responsive design, component structure, visual hierarchy, interaction states, accessibility, and frontend polish.
3. Keep business logic and provider integrations outside presentation components.
4. Build reusable components rather than putting the entire UI into a single page.
5. Implement loading, empty, success, error, and partial-generation states.
6. Ensure the interface works on desktop and mobile.

8. The frontend should communicate with Next.js API routes and Trigger.dev realtime functionality through clearly typed interfaces.

NEWS PROCESSING

Search multiple queries for each topic.

Use source-specific queries where useful.

Normalize URLs.

Remove duplicate URLs.

Extract article content.

Reject unusable article extraction results.

DEDUPLICATION

Use:
1. URL normalization
2. content/title hashing
3. semantic similarity
4. LLM event clustering where necessary

VERIFICATION

Create a dedicated verification stage.

The verifier must return:
- confirmed facts
- conflicting claims
- unverified claims
- timeline
- confidence score

Do not classify a claim as confirmed merely because one low-quality source reported it.

For major claims, prefer corroboration from independent credible sources.

NEWS SUMMARY

Return structured JSON:
- headline
- dek
- summary
- whatHappened
- keyDevelopments
- whyItMatters
- whatWeKnow
- whatWeDoNotKnow
- timeline
- sourceIds
- confidenceScore

Use Zod validation.

PODCAST

Generate a ~2 minute (260-320 word) professional spoken-news script.

Do not introduce facts absent from the verified briefing.

Use natural spoken language.

Generate MP3 using ElevenLabs.

Cache generated audio using a hash of all output-affecting parameters.

VIDEO

Use Remotion.

Do not use generative AI video for the MVP.

Create reusable React-based news graphics.

Scenes:
1. Intro
2. Headline
3. Key developments
4. Timeline
5. Why it matters
6. Sources
7. Outro

The video must include the podcast audio.

Use consistent visual branding.

SECURITY

The frontend must never call these providers directly:
- Tavily
- Firecrawl
- OpenAI
- ElevenLabs

The frontend must never receive:
- SUPABASE_SERVICE_ROLE_KEY
- Trigger.dev secret keys
- provider API keys

All privileged operations occur server-side.

ERROR HANDLING

Retry transient failures:
- 429
- 500
- 502
- 503
- 504

Do not blindly retry:
- 400
- 401
- 403
- 404

All failed workflows must update the newscast status to failed and store an actionable error message.

CACHING

Implement caching for:
- search results
- extracted articles
- summaries
- audio
- video

Use deterministic hashes.

Never regenerate identical expensive assets unnecessarily.

PROMPT VERSIONING

Do not bury unversioned prompts anonymously throughout the codebase.

CODE QUALITY

Prefer:
- small composable functions
- strict TypeScript
- typed interfaces
- Zod schemas
- dependency injection for external providers
- centralized error handling
- structured logging
- environment-variable validation
- reusable frontend components
- accessible interactive controls

Avoid:
- giant files
- giant functions
- duplicated API code
- hard-coded secrets
- direct provider calls throughout the UI
- untyped JSON
- unnecessary abstractions
- frontend components containing backend orchestration logic

MEDIA STORAGE

Do not store MP3/MP4 binary data in PostgreSQL.

Store media in Supabase Storage.

Store media metadata in PostgreSQL.

Recommended buckets:
- newscast-audio
- newscast-video
- newscast-images
- newscast-thumbnails
